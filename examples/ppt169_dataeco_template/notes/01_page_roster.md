# DataEco Reference Page Roster

This file records the verified semantic naming applied to the imported reference SVG pages in `svg_output/`.

## Naming Rule

- Prefix keeps original slide order: `P##`
- Middle segment expresses page family: `cover`, `toc`, `chapter`, `content`, `ending`
- Tail segment captures the main reusable layout intent
