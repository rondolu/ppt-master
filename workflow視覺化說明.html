      rework
      annotation 回修迴圈使用 live preview 的標註回收主觀落差，把封面、第二頁、結尾頁重新拉回 DataEco 一致性。
      export
      三次 timestamped export每一輪匯出都留下可追溯版本，最後定格在 110946 版本。

      為什麼它能這麼像 reference template

      1. 先把 template 變成專案內的可引用資產

      DataEco 不是只作為視覺靈感，而是先被 staged 成一整組 reference SVG roster。 這讓系統能引用具名頁型，而不是靠模型臨場回憶「大概長那樣」。

      2. 用 spec_lock 把版型語法鎖死

      顏色、字體、page rhythm、page layout mapping 都落進 execution contract。 Executor 每頁重讀它，所以 deck 不會在第 4、5、6 頁開始視覺漂移。

      3. 相似度來自約束加回修，不是一次抽樣

      先遵守版型，再經過 quality gate 與 annotation 迴圈修正偏差。 最終相似度高，是因為流程本身有收斂機制。
